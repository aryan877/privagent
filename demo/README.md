# PrivAgent Demo Materials

This folder contains demo scripts and materials for showcasing PrivAgent features.

## Quick Demo

Run the interactive demo:

```bash
uv run python demo/demo_script.py
```

This will show:
- 🔐 ZK Compression demonstration (99.9% savings)
- 📊 Privacy Score analysis with recommendations
- 🛡️ MEV Protection layers
- 👁️ Real-time monitoring alerts

## Demo Output

The script demonstrates all 4 key features with realistic output examples that you can show to judges or users.

## For Video Demo

When recording your demo video, you can:
1. Run this script to show the capabilities
2. Run the actual coordinator agent
3. Show live interaction via ASI:One chat interface

## Test Commands

Once agents are running, test these commands via ASI:One:
- `check my privacy score`
- `compress my tokens`
- `protect my swap from MEV`
- `help`
